# Documentation guidance

- Preserve source-of-truth precedence: owner decisions, accepted ADRs, approved specifications, architecture handover, versioned contracts, then implementation guidance.
- Keep the architecture handover descriptive. Record material architectural changes in an accepted ADR or explicit owner decision.
- Treat the envisioned feature catalogue as a catalogue, not a roadmap, priority list, or implementation mandate.
- Keep cross-links relative and update `docs/README.md` when adding a durable document category.
- Changes under `docs/architecture/` are critical-path governance changes and require explicit work-item authorization and Architecture Guardian review.
